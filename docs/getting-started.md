# Getting Started

DexSYS is a decentralized exchange project with a Rust (Axum) backend, a frontend, and smart contracts.

## Repository layout
- backend/ : Axum API server
- frontend/ : trading interface
- contracts/ : smart contracts
- docs/ : project documentation

## Documentation map
- 01-requirements : software requirements
- 02-design : design documents
- 03-api : API reference
- 04-testing : test plans
- 05-deployment : deployment notes
- adr : architecture decision records
